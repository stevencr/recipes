# Daily Recipes Skill

The repository's reusable agent skill now lives at:

`skills/daily-recipes/SKILL.md`

It is packaged as a portable OpenAI/Codex-style skill under the repository's `skills/` directory. The plugin manifest is at `.codex-plugin/plugin.json`.

Use the skill for recipe additions and maintenance rather than treating this file as the source of truth.

For ChatGPT, skills are installed/managed separately from GitHub repository documentation. The repository contains the portable skill source so it can be packaged or updated without duplicating the instructions.
